# Mettre à jour le site

Les contenus qui changent se trouvent dans ce dossier, au format JSON (texte simple) :

- `site.json` : annonce de la page d'accueil (`annonce_accueil`), coordonnées, horaires, bureau, liens d'adhésion et de don
- `events.json` : événements (les passés vont seuls dans les archives de « Nos activités »)
- `publications.json` : livres, extraits, miscellanées
- `gallery.json` : photos de la galerie (déposer l'image dans `assets/img`)
- `collections.json` : frise chronologique de l'Hôtel-Dieu

Les textes « [À COMPLÉTER] » sont des textes d'attente à remplacer.
