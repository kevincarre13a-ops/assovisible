# Mettre à jour le site

Les contenus qui changent se trouvent dans ce dossier, au format JSON (texte simple) :

- `events.json` : événements et expositions (les passés vont seuls dans les archives)
- `news.json` : actualités
- `collections.json` : collections et frise chronologique
- `gallery.json` : photos de la galerie (déposer l'image dans `assets/img`)
- `site.json` : coordonnées, horaires, tarifs, bureau, liens d'adhésion et de don

Les textes « [À COMPLÉTER] » sont des textes d'attente à remplacer.
